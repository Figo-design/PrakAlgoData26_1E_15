Jawaban
1. Front = -1 dan rear = -1 karena queue masih kosong, sedangkan size = 0 artinya belum ada data
2. Digunakan untuk circular queue, jika rear sudah di posisi terakhir array maka akan dikembalikan ke indeks 0, tujuannya agar ruang array bisa dipakai lagi
3. Digunakan untuk circular queue, jika front sudah di posisi terakhir array maka akan dikembalikan ke indeks 0, tujuannya agar proses pengambilan data tetap berjalan melingkar
4. Karena data queue, posisi awal berada di front bukan 0, jika dimulai dari 0 akan menampilkan data kosong atau data yang sudah keluar
5. Digunakan untuk perpindahan indeks secara melingkar, jika i sudah di akhir array (i + 1) % max akan kembali 0
